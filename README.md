# ATM for Teens

A Python ATM simulation that I'm creating as a learning project.

The idea is to build a simple ATM system designed around teenagers, with features such as account management, spending limits, deposits, withdrawals, and transaction history.

I started this project to practice Python (Just like https://github.com/Stonyax97/MiniGameStore) and explore new programming concepts. As I learn more, I plan to keep improving the project and implementing what I learn along the way. This is also more interesting since it's closer to a real world app/scenario rather than a useless game store.

## What I'm Learning Through This Project
- Classes and OOP
- Functions and modular programming
- File handling and JSON
- User authentication
- Saving and loading data
- Working with multiple accounts
- Basic project architecture

## Version History

Each version represents a stage of development and something new I've learned or practised.

This repository also serves as a record of my progress, including changes, experiments, and improvements.

## Project Status

This is an ongoing learning project. It is not intended to be a real banking application or used to manage actual money (OBVIOUSLY).
